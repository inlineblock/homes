# Reusable cabinetry modules

- Search these modules before building bedroom storage, kitchens or utility joinery. Build runs from linked modules; retain project-specific continuous worktops, corners and filler panels in the home.
- Preserve nominal dimensions and front direction. Do not stretch cabinets as a shortcut: select the appropriate module width or publish a clearly named dimensional sibling when the size must coexist, recording its real parent ID/version. Use a new version for a compatible revision of the same identity.
- Verify usable internal volume, fronts, handles, toe kicks and placement origin. Wardrobes must include a shelf and hanging rail, with standing clearance and door operation accounted for in the host home's plan.
- A wardrobe box does not establish bedroom legality. The home must separately review circulation, glazing/egress assumptions, storage access, furniture and applicable jurisdiction-specific requirements.
- `oak-wardrobe-2ft/v001`: floor-center origin, front -Y, 2 x 2 x 8 feet; handles project a further 0.094 feet. Group three modules for six feet of storage.
- `oak-drawer-base-2ft/v001`: floor-center origin, front -Y, nominal 2 x 2 x 2.86 feet, no worktop. Continuous counters are host assemblies, and fronts project slightly beyond the nominal depth.
