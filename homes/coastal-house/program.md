# Coastal House program review

The current revision introduces a raised glazed pavilion, real vaulted ceilings and exposed driftwood beams matching the attached pergola. Reopened geometry, all 38 pinned shared assets and lighting pass the current checks. The current closed-envelope IFC has zero schema errors and passes actual Bonsai import; the fourteen-view render set and coordinated drawings/booklet have been visually reviewed. Presence in the model establishes concept geometry, not product fit, engineered performance or local approval. See [design intent](design-intent.md) for alternatives and the selected direction.

The current [native receipt](model/model-validation.json) confirms the reopened attached-pergola model: two outer posts, no house-side columns, ledger contact with the header, 30 ft sliding-wall coverage and a 3.10 ft minimum slat-to-soffit clearance. Twenty interior routes, four terrace routes, two arrival routes, two driver approaches and 420 panel-component checks across seven frames passed. The [adoption receipt](model/asset-adoption.json) confirms all 38 asset versions match the manifest. These are concept geometry checks, not structural approval, full equipment/door operation or occupied-seating validation. See [design-review.md](design-review.md).

The [IFC validation](model/ifc-validation.json) and [Bonsai import receipt](model/bonsai-validation.json) verify the current export: the imported model meshes, all four roof planes, the upper glazing and exposed-frame assembly, attached two-post pergola and facade-panel geometry. The native and IFC file hashes match the import receipt. This is classified concept geometry rather than an engineered building model. The current gallery contains fourteen reviewed native views: six refreshed for this revision and eight retained because the changed wall is outside their visible content. The exterior and two interior Imagegen studies, floor plan and all ten booklet pages were refreshed and reviewed; site and roof-section drawings remain unchanged. The [output receipt](model/output-validation.json) records their current hashes.
