# Architectural hardware

- Before making a handle, knob or pull inside a home, search this catalog. Link an appropriate pinned collection and record its dependency; repeated local cylinders are not a replacement for a shared handle asset.
- Preserve real fixing centers and projection. Keep instances at scale 1; publish another dimensional version or asset when changing size.
- Mounting origins lie on the host face; front points toward local -Y and Z is up. Read the asset's mounting notes before placement. A recessed pull requires a real cutout; an edge pull requires the stated rebate. Do not embed hardware in a solid door face or let it float.
- Choose one coherent principal finish per room, with deliberate exceptions. Brushed steel, matte black and satin bronze are appearance studies, not claims about a commercial finish or marine suitability.
- Cabinet pulls, door levers and sliding-door pulls have different functions. Do not use a drawer knob as a latch assembly. Show the host door's operation and clear opening separately.
- Native assets are editable original geometry; do not overwrite an adopted version. Inspect the actual preview and reopen the native asset before approving a new publication.
