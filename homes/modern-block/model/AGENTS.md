# Modern Block native and interchange models

- `modern-block.blend` is the editable furnished presentation scene. `modern-block.ifc` is a classified **IFC4 concept interchange model**, not a complete semantic equivalent of the Blender furniture/landscape scene and not permit or construction documentation.
- One assigned owner writes the native binary and its generated IFC per run. Preserve user-authored native edits before rebuilding; do not run concurrent writers or save a temporary IFC import over the presentation file.
- Reproduction commands and overwrite behavior are maintained in [authoring guidance](../../../tools/modern_block/AGENTS.md). Use **Blender 4.5.14 LTS** for the verified native baseline; see [software setup](../../../docs/software.md) for the compatible Bonsai/IfcOpenShell installation. Supply executable/runtime locations through the documented environment variables, never new hardcoded user paths.
- Restore Git LFS content and retain exact linked library versions. Saved native dependencies must use repository-relative paths; inspect actual linked instances after reopening. Material and hardware dependencies nested inside assets remain part of the model.
- `opening-schedule.json` is generated by scene assembly and consumed by the plans. `native-validation.json` records fresh native checks; `ifc-validation.json` records IFC schema checks; `bonsai-validation.json` records a separate real Bonsai import. These receipts are regenerated and are not interchangeable evidence or blanket design approval.
- Author measurements in meters, present plan dimensions in feet/inches, and retain the explicit area convention in `project.json`. Coordinate design constants, modeled openings, interior placement records, plans, area schedules and asset adoption together.
- The source render path points to `../outputs/work/`. Render and review there before promoting current images; keep camera-only operating-state changes transient. Inspect all affected actual images and plans, then update gallery/provenance registrations. Do not label command completion or schema validity as visual review.
- Keep identifying reference-project names, people, locations, addresses, social links and source-property URLs out of model names, custom properties, external links, IFC metadata and receipts. Use only the neutral Modern Block identity and documented original concept assumptions.
