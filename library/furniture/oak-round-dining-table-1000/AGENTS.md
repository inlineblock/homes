# Shared original furniture

- Read the version manifest for actual dimensions, front direction and floor origin.
- Link and instance the collection at scale 1. Preserve adopted versions; publish another size as a distinct sibling.
- Keep upholstery, supports and frame together. Bed assets contain one bed frame; nightstands are separate assets.
- Verify placement and operating/standing space in the host, including dining-chair pullback. Asset bounds alone are not a circulation check.
