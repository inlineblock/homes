# Premium stack interface

- One native instance contains one lower washer and one upper dryer. Two instances mean four machines. Never place the dryer below the washer or scale to fit.
- Distinguish 1711 mm modeled stack height from the 1800 mm reserved installation envelope. Exact current stacking-kit dimensions and structural support require selected-product confirmation.
- Use the original generic geometry honestly: official Miele dimensions are a planning precedent, not a claim that this mesh is approved manufacturer CAD.
- Check complete door sweep plus independent human/basket space. Front-loading space is not automatically a clear passage, and rear hose space is additional to product depth.
- Preserve accessible shutoffs, drainage, power, dryer air intake/filter/condensate access and a whole-appliance removal route. Never hide these behind sealed cabinetry.
