# Shared windows and glazed openings

- Read the parent library guidance and the selected version's `asset.json` before placement. Reuse a pinned native collection; keep its required hardware/material dependencies declared by ID, version and relative path.
- Keep real frame sightlines, sill projections and handle depth when changing dimensions. Publish a reviewed size variation for a resolved design instead of stretching a finished product assembly. If scaling is used for an early appearance study, state that limitation in the home's asset schedule and review.
- A visible window is not a wall opening: the adopting home must cut the wall, coordinate sills/heads and furniture, and check the full operating and cleaning envelope. Distinguish fixed glazing, operable windows and passage doors in schedules.
- Record origin, inside/outside direction, nominal opening, actual bounds and closed/open state. Concept grips are not certified window-lock hardware. Do not invent thermal, weather, structural or escape ratings.
- Reopen the native asset and inspect its preview before publication. The adopting home must also inspect it in its actual sunny/shaded facade views. Preserve earlier adopted versions and contribute reusable changes back to this library.
