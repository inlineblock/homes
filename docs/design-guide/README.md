## Selection sequence

1. Read the user's household/site/style priorities. Record missing information as assumptions; ask only when it materially changes work that cannot proceed independently.
2. Apply functional baseline across every tier. Select premium/custom options deliberately; do not add prestige features at the expense of circulation, daylight, durability or useful storage.
3. Resolve climate/site constraints before choosing assemblies. Price or appearance does not establish water, snow, wind, fire, corrosion or energy performance.
4. Check the library. Adopt compatible assets, create a versioned variation where needed, and contribute generally useful work back. Keep a feature-to-asset schedule.
5. Coordinate space and interfaces: fixture dimensions, open doors, appliance exhaust, roof drainage, structural load paths, ceiling cutouts and service/replacement access.
6. Inspect the native model and current drawings, test important geometry, and inspect real rendered views. Document remaining site/product/engineering decisions accurately.

## Evidence labels

Use: **requested**, **assumed**, **selected concept**, **modeled**, **dimensioned reservation**, **manufacturer selected**, **engineered**, **approved**, **field verified**. These are not interchangeable. A rendered appliance is not a product specification; a classified IFC is not a coordinated construction model; a checked walking route is not accessibility approval.
