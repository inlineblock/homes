![Underbody and service access](service-preview.png)

Original generic concept equipment; CC BY 4.0, Homes project contributors. Link the named collection in `gas-cooktop-36in.blend`, centered on the countertop mounting plane with controls toward −Y. Preserve its real dimensions.

Read `asset.json` before installation: the flange is larger than its concept cutout, the underbody needs a real opening and access, and separate extraction and an oven must be provided. These allowances are not manufacturer specifications.

Rebuild and fresh-process verify using `tools/library/build_cooktop_options.py`; published versions are immutable. Native preview includes a temporary neutral support counter, not part of the asset. Host integration is pending.
