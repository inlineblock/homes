# Native plant gallery

**35 built families · 105 named variants.** These images are native Blender previews of original mesh geometry. Each main image presents the family’s three collections; the detail link shows actual modeled foliage, fruit or flowers. All 35 families passed fresh native reopen/link checks and review of these whole-family and detail images; each linked receipt records the current native/image hashes and findings. The scope is architectural concept landscaping, with simplified botanical geometry rather than photoreal foreground macro vegetation. No new home adoption is implied.

[Selection notes and botanical sources](README.md) · [Machine-readable catalog](catalog.json) · [Comparative linked nursery](nursery/README.md)

The six pre-existing families remain listed in the [plant library](README.md#existing-families). This gallery focuses on the new expansion.
