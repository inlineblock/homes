# Timber Courtyard tools

- Exterior composition is authoritative; the image's room layout is not. Keep exact area inputs in `design.py`.
- Reuse the shared geometry, material, landscape, and library tools. Pin shared `.blend` assets by version and use relative links.
- Author standing seams as geometry and timber at real board scale; avoid fake image overlays as a substitute for the model.
- Render a front exterior and elevated view, then inspect both before reporting completion. Keep schematic interiors explicitly labeled.
- `gallery.py` owns camera names/poses and stable render filenames. For a camera-only gallery extension, use `prepare_gallery.py` on the saved native model; it checks that non-camera geometry, effective materials, lights and visibility remain unchanged.
- `verify_gallery.py` is the fresh-file validation entry point without rendering. `render_gallery.py` writes candidates only to ignored `outputs/work/`; inspect pixels before promotion and never save temporary cutaway states over the native scene.
- `walkthrough.py` builds a separate presentation camera scene; `--build` invalidates its disposable frame cache, while `--animate` resumes an interrupted sequence. Review the whole video before `--promote`, then reopen with `verify_walkthrough.py`. Keep the canonical home unchanged and disclose open-leaf overrides and existing schematic interior gaps.
- `verify_walkthrough_support.py` separately measures sampled floor/ground support and low rails along the route; its default receipt stays in ignored work. Report raised tracks, paving/soil transitions and finite sampling limits alongside body clearance. Supported modeled passage is not a level, step-free or accessibility-approved route.
- `finish_walkthrough.py` produces a local, geometry-conditioned AI test. Review it against the native motion before `--continue-tour`; that continuation uses the previous clip's final frame plus photographic anchors at their measured route frames. All AI candidates remain in ignored work until camera continuity, openings, room layout and every segment boundary are reviewed. A still-image pan, an unconditioned AI clip or an attractive but altered house does not pass.
- Add exact endpoint references when a new view reveals ambiguous geometry or materials; in this tour, a start-only reference let the cedar gable drift into sky-colored glass. Reuse an identical selected reference when the native camera holds the same pose. If source motion, prompts or references change, invalidate the affected candidate clips and following dependent clips before resuming; a complete cached file is not proof that it matches new inputs.
- A reviewed, hash-checked shared boundary may be fixed explicitly in `boundary-anchors.json` to repair an upstream section without changing the downstream section's actual inputs. Record its origin honestly, condition both sections on that same image, and inspect the repaired join. Never claim an AI-derived boundary is an Image Gen photograph or a native render.

- `kitchen.py` owns the coordinated kitchen/pantry assembly and `kitchen_layout.py` shares its measured plan coordinates. `revise_kitchen.py` produces an ignored candidate from the existing native home; review fit and renders before promotion. The full builder installs that same assembly. Generic cabinet/appliance geometry belongs in pinned library assets.
- For an isolated reproducibility check, run `build.py -- --output-home homes/timber-courtyard-02/outputs/work/rebuild`, then `verify_kitchen.py -- --file homes/timber-courtyard-02/outputs/work/rebuild/model/timber-courtyard-02.blend --output homes/timber-courtyard-02/outputs/work/rebuild/kitchen-validation.json` through Blender. The builder records transitive native dependencies as well as directly adopted assets. An isolated rebuild does not replace or revalidate the current gallery or film.
- Kitchen revisions invalidate affected native gallery views, plans, photographic studies and walkthrough reference/video frames. Regenerate them together; do not keep an obsolete film labeled current after changing its source model.
