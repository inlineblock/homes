# Editable models

- `atrium-01.blend` is the furnished presentation scene. `atrium-01.ifc` is the architectural interchange model for Bonsai.
- Keep meaningful object and collection names: architecture, roof, kitchen, furniture, landscape, lighting, cameras.
- Preserve metric scale and relative library links. Do not pack the shared tile into a home-specific anonymous material.
- Expose roof visibility and named cameras for review. Do not save the only model with essential parts deleted merely to obtain a cutaway.
- Reopen generated files before delivery. Record any material or semantic differences between IFC and Blender in the project README.
