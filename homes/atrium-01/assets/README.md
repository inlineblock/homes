## Selection and derivation

The original sage fluted tile, walnut counter stool and opal pendant preserve the kitchen identity. Warm walnut and ten companion cabinet/appliance assets were published for this revision, deriving from the real existing oak/smoked-oak parents without changing those versions. Lower plumbing-ready vanity bases and dedicated cleaning cupboards resolve actual installation needs. The library contains the native previews, dimensions, derivation and fresh-link evidence. Original project geometry and finishes use CC BY 4.0, attribution Homes project contributors; authoring code uses MIT.

The smaller olive collection fits the open court; full-size broad-canopy trees sit in the surrounding illustrative garden. No plant is represented as an approved species for an identified climate. Standard pavers retain rigid dimensions; perimeter bases/cuts are host work.

Ten bedroom bays adopt four new rigid roller-shade sizes. Each links separate raised and lowered collections with opaque woven fabric. The normal model and IFC show raised shades; a dedicated native view shows the alternate lowered state. Actual fabric-to-glass overlap, cassette spacing, wall/beam clearance and furniture intersections are checked in the host. These are privacy concepts, not a tested room-blackout or light-sealing specification.

## Deliberately bespoke host work

The enclosure, post-and-beam infill glazing, coordinated sliding tracks/door pockets, roof/fascia/support layout, roof and court drainage, ceiling apertures, terrain and carport/walk arrangement depend on this particular plan. Continuous worktops with real fixture apertures, installation fillers, island end panels, the court masonry seat and service/vehicle clearance reservations also remain host geometry. These do not replace shared cabinet, fixture, furniture or landscape modules.

Asset publication verifies the component in isolation. Host verification separately checks relative links, placement, actual evaluated bounds, kitchen openings and operation, fixture heights, storage, circulation and the sheltered parking route. Unselected manufacturer requirements, engineering and site performance remain outside those concept checks.
