# Lindon listing-based concept tools

- All layout data and public claims distinguish listing evidence, photo-derived approximation, and proposed design changes. Read the project's reference notes before changing the model.
- Dimensions in these tools are meters. `utils.py` adapts older feet-based shared helpers; do not convert twice.
- `design.py` owns the traced concept plan. Scene, plans and schedules use that common source. No source photograph or third-party floor-plan image belongs in generated public outputs.
- Keep facade/window updates coordinated across the native model, gallery and opening schedule. Preserve the angled garage wing and rear walkout/deck relationships unless explicitly redesigning them.
- One agent owns the home native file; coordinate library publication and serialize GPU renders. Drafts go to ignored `outputs/work/` until inspected.
