# Render review

- Commit only selected useful images; put throwaway iterations in ignored `work/`.
- Kitchen view is the primary deliverable. Inspect full-size renders, not only logs or thumbnails.
- Check counter/sink edges, stool placement, glass, tile scale, cabinet joins, exposure, and geometry intersections.
- Render from the actual model. Do not substitute an AI-generated concept image and imply it proves model quality.
