# Asset guidance

Read `asset.json`, `README.md` and `validation.json` before use. Preserve this version after adoption. Rigid placement only; do not stretch plumbing interfaces. Do not infer a compatible cabinet from nominal width: rails, bowl, flange, faucet mount, services and operating space must be checked. Publish a new variant for interface changes and link the exact version. The studio preview is not a checked home installation.
