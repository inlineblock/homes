# Cream Inset Appliance Garage 48In

Original reusable concept assembly. Nominal carcass: 1.2192 × 0.6500 × 1.2000 m; projecting hardware is included in the [measured manifest](asset.json). Front is −Y, width X, up Z. Use rigid placement only.

Closed collection: `cream-inset-appliance-garage-48in | v001`. Operating-state collection: `cream-inset-appliance-garage-48in | open v001`. Select the collection explicitly when linking; both occupy the same placement origin. Where present, moving fronts, attached hardware and boxes are grouped under separate hinge or carriage roots. Countertops and host openings are supplied by the home.

**Bifold operation:** open the two outer hinges to 100° first, then fold the inner leaves to 165°. Reverse the sequence to close. Driving all four angles proportionally can make the opposite inner leaves collide. This is a staged concept mechanism, not a specified product.

Z=0 mounts on a host countertop. The appliance bay, upper shelf and rear slotted grille bands are real geometry. The outlet reservation is a planning volume, not electrical equipment: the host must install an actual appropriate outlet and provide plug/cord access.
