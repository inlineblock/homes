# Warm walnut

[Manifest](asset.json) · [Native material](warm-walnut.blend) · [Validation](validation.json)

![Native neutral-light material sample](preview.png)

Original natural-brown walnut appearance derived from the physical-meter grain algorithm used by smoked-oak/v001. Use the material named `Warm walnut | natural brown | v001` and apply `common.timber_materials.grain_uv` to finished-size local meshes. The shader varies grain phase and tone per object, with 25mm broad figure and 3mm fine fibers. It contains no external textures.

The neutral preview includes vertical boards and a horizontal member to show grain direction. Review final sunny and shaded host views separately. This is an illustrative finish rather than a specified product or exact timber specimen. CC BY 4.0; attribution Homes project contributors.
