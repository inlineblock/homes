# Blue grama

Original illustrative botanical geometry; not a certified species identification, nursery specification, or climate suitability approval.

Original editable mesh asset, in meters with Z up and the plant base at the origin.

## Collections

Link one collection from the Blender file for each planting instance; variants share the same origin intentionally.

| Variant | Collection | Modeled size (W × D × H, m) | Description |
|---|---|---|---|
| young-green | `blue-grama__young-green` | 0.44 × 0.39 × 0.23 | Young green bunch; lower narrow arching blades, no mature seedheads. |
| eyelash-seedheads | `blue-grama__eyelash-seedheads` | 0.68 × 0.64 × 0.66 | Mature arching blue-green bunch with one-sided comb-like eyelash seedheads. |
| dormant-straw | `blue-grama__dormant-straw` | 0.57 × 0.60 × 0.58 | Dormant straw bunch with splayed stems and retained dry asymmetric seedheads. |
